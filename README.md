# Awesome Isabelle

Follow an Isabelle/HOL theory from an interactive proof to a reusable session. Check the object logic when following examples, especially Isabelle/ZF material.

- [Isabelle](https://isabelle.in.tum.de/) — Install a release and open its bundled examples in Isabelle/jEdit.
- [Isabelle manuals](https://isabelle.in.tum.de/documentation.html) — Begin with Programming and Proving in Isabelle/HOL. Use the Nitpick manual when exploring small countermodels.
- [Archive of Formal Proofs](https://isa-afp.org/) — Find a theory by topic and download the archive for your Isabelle release.
- [Community](https://isabelle.systems/) — Find community learning materials and discussion channels.

## A first exercise

Open a small AFP entry and locate its ROOT file. Identify the parent session, then follow one theorem back to the theories it imports.
